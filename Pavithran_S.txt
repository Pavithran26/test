Aim:
To calculate, analyze, and compare network performance metrics including latency, throughput, and available transmission bandwidth using Python.

bandwidth = float(input("Enter bandwidth (Mbps): "))
data_size = float(input("Enter data transferred (MB): "))
time = float(input("Enter transfer time (seconds): "))

print("Bandwidth:", bandwidth, "Mbps")

    print("Latency Status: Moderate")

    print("Latency Status: High")

EXPERIMENT 04: CYCLIC REDUNDANCY CHECK (CRC) ERROR DETECTION
============================================================

Aim:
To implement Cyclic Redundancy Check (CRC) error detection using modulo-2 binary division (XOR operation) and verify data integrity on the receiver side.

Source Code (Python 3):

def crc_division(data, generator):
    data = list(data)
    generator = list(generator)
    for i in range(len(data) - len(generator) + 1):
        if data[i] == '1':
            for j in range(len(generator)):
                data[i + j] = str(int(data[i + j]) ^ int(generator[j]))
    return "".join(data[-(len(generator) - 1):])

# Sender side
data = input("Enter data bits: ")
generator = input("Enter generator bits: ")
appended_data = data + '0' * (len(generator) - 1)
remainder = crc_division(appended_data, generator)
transmitted_data = data + remainder

print("\nCRC Remainder:", remainder)
print("Transmitted Data:", transmitted_data)

# Receiver side
received_data = input("\nEnter received data: ")
check_remainder = crc_division(received_data, generator)
print("Checking Remainder:", check_remainder)

if '1' in check_remainder:
    print("Error detected in received data.")
else:
    print("No error detected. Data received correctly.")

EXPERIMENT 06: HAMMING CODE (7, 4) FOR SINGLE-BIT ERROR DETECTION AND CORRECTION
============================================================

Aim:
To implement Hamming Code (7, 4) in Python to compute redundant parity bits, locate erroneous bit positions using syndrome bits, and automatically correct errors.

Source Code (Python 3):

def calculate_parity_bits(data):
    m = len(data)
    r = 0
    while (2 ** r) < (m + r + 1):
        r += 1
    n = m + r
    hamming = ['0'] * (n + 1)
    j = 0
    for i in range(1, n + 1):
        if (i & (i - 1)) != 0:
            hamming[i] = data[j]
            j += 1
    for p in range(r):
        position = 2 ** p
        parity = 0
        for i in range(1, n + 1):
            if i & position:
                parity ^= int(hamming[i])
        hamming[position] = str(parity)
    return "".join(hamming[1:])

def detect_error(received):
    n = len(received)
    received = ['0'] + list(received)
    error_position = 0
    position = 1
    while position <= n:
        parity = 0
        for i in range(1, n + 1):
            if i & position:
                parity ^= int(received[i])
        if parity != 0:
            error_position += position
        position *= 2
    return error_position, received

data = input("Enter data bits: ")
hamming_code = calculate_parity_bits(data)
print("\nGenerated Hamming Code:", hamming_code)

received = input("\nEnter received Hamming Code: ")
error_pos, rec_data = detect_error(received)

if error_pos == 0:
    print("No error detected. Received data is correct.")
else:
    print("Error detected at position:", error_pos)
    rec_data[error_pos] = '1' if rec_data[error_pos] == '0' else '0'
    print("Corrected Hamming Code:", "".join(rec_data[1:]))

EXPERIMENT 07: STOP-AND-WAIT SLIDING WINDOW PROTOCOL SIMULATION
============================================================

Aim:
To simulate the Stop-and-Wait flow control and ARQ reliable data transfer mechanism with timeout retransmissions and acknowledgments using Python.

Source Code (Python 3):

import time

def stop_and_wait(frames):
    for i in range(1, frames + 1):
        while True:
            print(f"\nSender: Sending Frame {i}")
            time.sleep(0.5)
            print(f"Receiver: Frame {i} received successfully")
            time.sleep(0.5)
            ack = input(f"Enter ACK for Frame {i} (Y/N): ").upper()
            if ack == 'Y':
                print(f"Sender: ACK {i} received")
                print(f"Frame {i} transmitted successfully")
                break
            else:
                print(f"Sender: ACK {i} lost")
                print(f"Sender: Retransmitting Frame {i}")
    print("\nAll frames transmitted successfully.")

# Input total frames and execute simulation
n = int(input("Enter the number of frames: "))
stop_and_wait(n)

EXPERIMENT 08: FRAME CREATION USING CHARACTER (BYTE) STUFFING
============================================================

Aim:
To implement framing at the Data Link Layer using character (byte) stuffing to distinguish payload data from delimiter flag sequences.

Source Code (Python 3):

def character_stuffing(data):
    FLAG = 'F'
    ESC = 'E'
    stuffed_data = FLAG
    for char in data:
        if char == FLAG or char == ESC:
            stuffed_data += ESC
        stuffed_data += char
    stuffed_data += FLAG
    return stuffed_data

# Input and framing
data = input("Enter the data: ")
result = character_stuffing(data)

print("\nOriginal Data:", data)
print("Stuffed Frame:", result)
